# Ranman Machine Industries (RMI) — Official Landing Page Demo

A stunning, fully responsive, production-grade landing page demo for **Ranman Machine Industries**, an engineering-based food processing and agricultural machinery manufacturer based in Coimbatore, Tamil Nadu, supplying across PAN India.

---

## 🌟 Overview & Key Highlights

- **Aesthetics & Design System**: High-end industrial modern aesthetic with dark slate/charcoal backgrounds (`#090D16`, `#0F172A`, `#1E293B`), vibrant safety orange accents (`#F97316`), and crisp metallic typography using Google Fonts (**Plus Jakarta Sans** & **JetBrains Mono**).
- **Self-Contained Architecture**: Built in clean, lightweight, single-file HTML with embedded Tailwind CSS via CDN, Lucide Icons, and zero heavy frameworks.
- **Micro-Animations & Parallax**: Hardware-accelerated transform parallax with subtle layered depths, supporting mobile screens and fully respecting `prefers-reduced-motion`.
- **B2B Entrepreneur Tooling**: Includes an interactive **ROI & Capacity Calculator** where farmers and MSME food processors can calculate daily throughput, monthly profits, and CapEx payback timelines.

## 🖥️ How to Run Locally

You can open `index.html` directly in any modern browser:

```bash
# Clone the repository
git clone https://github.com/Speedyy29/Runman.git

# Navigate into the folder
cd Runman

# Open directly or start a local server
python -m http.server 8080
```

Then visit `http://localhost:8080` in your web browser.
